Bringing Modern Campus to a personal workspace

MicroHub’s off-white surfaces, navy text, and teal controls set the direction. The portfolio adapts these tokens to a desktop sidebar, a mobile navigation bar, and project cards.

The workspace illustration is a local SVG. The avatar has smaller WebP variants so a tiny profile image does not require the original full-size file.

The implementation includes visible keyboard focus, reduced-motion support, and browser checks at phone, tablet, and desktop widths.
