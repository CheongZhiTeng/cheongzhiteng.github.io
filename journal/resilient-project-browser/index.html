Reliability · 2026-11-18

A project browser that survives a failed request

The portfolio fetches public repositories from GitHub, but a failed request should not leave the page empty. It starts with a curated collection and uses the last successful response when one is available.

Unknown statistics stay unknown. Featured fallback cards do not invent star counts or update dates, and the interface explains which data is being shown.

The browser checks exercise success, failure, and cached recovery separately. That makes the fallback part of the product rather than a rarely tested error screen.
